# 中文段落润色

先读完整段，弄清作者想让读者知道什么、凭什么这样说。找出原文最有信息量的一句，判断放在哪里最合适。方法段通常要让同行知道怎么做，讨论段要交代结果能解释到哪里。普通文章沿用作者与读者之间原有的距离。已经说得自然、准确的句子可以原样保留。

## 怎样落笔

| 阅读时遇到的情形 | 修改时的判断 |
| --- | --- |
| 标点替文字制造强调 | 去掉术语外围的装饰性引号，读一遍，看句意是否仍然完整。插入语太长时把它还原成一句话。直接引语、量表条目、公式、区间及学科惯用符号按原样保留。 |
| 一段论述被拆成许多条目 | 看条目之间有没有正文需要的关系。例如材料如何用来回答问题，可以连起来写。可独立勾选的条件、操作步骤和作者指定的列表沿用其格式。 |
| 对举反复出现 | 先写作者真正主张的那半句。另一半若对应竞争解释、对照组或容易混淆的概念，保留具体差别，交代两者各自如何定义或测量。 |
| 抽象名词连续出现 | 回原文找动作、对象与条件。原稿写了两张表按学号核对，就直接写出核对过程。原稿只有“协同”二字时，不能自行添入参与单位和流程。 |
| 段末突然谈及行业或时代 | 看结尾能否从本段材料推出。纯评价可删，确有实践含义就限定对象和用途。方法段写清一个影响解释的限制，也可以就此收住。 |
| 开头换个题目也能成立 | 试从样本中的现象、作者要回答的问题或一个定义落笔。时间、制度等背景若决定了研究对象的范围，把它留在读者需要的地方。 |
| 数字、案例或文献支撑不足 | 逐项对照作者提供的材料。已有引文跟随原主张移动。遇到可疑数据保留原值，另行指出待核出处。不要补调查、页码、访谈原话或研究结果。 |
| 句首被“首先”“此外”等占满 | 暂时拿掉连接词，检查读者能否跟上。让上一句的对象成为下一句的主语。删词会模糊条件、让步、先后或因果时，保留表达该关系的词。 |

处理真正影响阅读的几处即可。术语前后一致有助于追踪变量。别为了措辞多样，把“意愿”换成“行为”，也别靠口头禅、错别字或编造个人经历制造自然感。

## 交稿前

把改稿当作同行第一次读到的文字，再与原稿逐句对照。谁做了什么、用了什么单位、在什么条件下观察、结论适用于谁，都应能从原文找到依据。特别检查否定、分母、方向和时态。“拟检验”仍属研究计划，“未观察到差异”仍有别于“两组相同”。若简化后丢失了关键信息，恢复那项细节。

默认直接交付可替换进原文的段落。作者要求说明时，挑会影响理解的改动解释。若原文有实质歧义或出处待核，将给作者的简短注记放在正文外。只有用户指定外部检测并明确送检文本时才提交，按报告原有指标记录原稿与改稿，区分片段得分和字符占比。
